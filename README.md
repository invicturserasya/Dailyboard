# DailyBoard 📌

Aplikasi dasbor harian berbasis web untuk mengelola tugas harian, menyimpan catatan, serta mengecek cuaca dan kutipan motivasi harian secara praktis.

## ✨ Fitur Utama
- 📝 **Daftar Tugas (To-Do List):** Tambah, hapus, edit tugas (*double-click*), serta tandai status selesai.
- 🔍 **Pencarian & Filter:** Cari tugas secara langsung dan filter status (*Semua*, *Selesai*, *Belum Selesai*).
- 🖐️ **Drag & Drop:** Atur ulang urutan daftar tugas dengan cara digeser.
- 📌 **Catatan Harian:** Simpan dan ubah catatan singkat berbasis *LocalStorage*.
- 🌤️ **Informasi Cuaca:** Integrasi API untuk mengecek kondisi cuaca berdasarkan nama kota.
- 💬 **Kutipan Motivasi:** Menampilkan kata-kata inspiratif otomatis dari API.
- 🌙 **Mode Gelap (Dark Mode):** Pilihan tema tampilan terang dan gelap.

## 🛠️ Teknologi yang Digunakan
- **HTML5 & CSS3** (Struktur & Tampilan)
- **JavaScript (ES6 Modules)** (Logika aplikasi & modularisasi file)
- **Browser LocalStorage** (Penyimpanan data sementara di browser)
- **Fetch API** (Pengambilan data cuaca & kutipan)
